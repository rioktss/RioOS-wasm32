# Dokumentasi MyKernel WASM32

Mulai dari [Build and Run](BUILD_AND_RUN.md). Dokumentasi arsitektur ada di [ARCHITECTURE](ARCHITECTURE.md), batas platform dijelaskan pada [WASM32_PORT](WASM32_PORT.md), dan penggunaan shell pada [TERMINAL](TERMINAL.md).

Proyek ini adalah build terminal-only: tidak menyertakan UI grafis, framebuffer, atau aplikasi RPK. Browser entry page `index.html` berada langsung di root.
