# Roadmap

- Perluas shell command dan utilitas file tanpa menambah UI grafis.
- Perkuat error reporting pada storage/localStorage browser.
- Tambahkan pengujian browser otomatis untuk startup, input terminal, resize viewport, dan kuota penyimpanan.
- Tingkatkan dukungan process metadata, scheduler policy, dan virtual memory yang sesuai dengan model linear-memory WASM.
